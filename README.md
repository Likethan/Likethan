## 💡 Contribution Guidelines

Before submitting a contribution, please ensure that:

- Code follows the existing project structure.
- Components are reusable whenever possible.
- New features are documented.
- Existing functionality is not broken.
- Commit messages are meaningful.
- Pull requests contain a clear description.

---

## 🐞 Reporting Issues

If you encounter a bug or unexpected behavior, please create an issue with the following information:

- Operating System
- Browser (if applicable)
- Node.js Version
- Steps to Reproduce
- Expected Behavior
- Actual Behavior
- Screenshots (if available)

Providing detailed information helps resolve issues more efficiently.
